# materin-ops 格物 · 产品功能表述

> 版本：2026-10-11 ｜ 模块：系统基座 / 需求管理 / 工单 / 开发者中心 / 通知 / 资源

## 1. 产品定位

materin-ops（格物）是面向运维团队的**一体化运维中台**：以 RBAC 权限为基座，提供需求管理、工单系统（ITR + SLA）、开发者中心（开放 API）、站内通知、文件资源五大业务能力。前后端分离（Vue Vben Admin 5 + Spring Boot 3 多模块），Docker Compose 一键部署。

## 2. 角色与权限模型

| 角色 | 能力概览 |
|---|---|
| super_admin | 全部功能 + 全部数据 |
| 普通登录用户 | 提交工单（报障人人可用）、管理自己的通知、个人中心 |
| 被授权用户（product_member） | 仅见授权产品下的需求/项目/迭代/任务/看板数据 |
| 开发者 APP（第三方） | 按授权接口清单调用开放 API（HMAC 签名，与登录体系双通道并行） |

权限三件套：菜单（目录/菜单/按钮三级）、角色-菜单绑定、按钮级权限码（`xxx:yyy:zzz`）。super_admin 返回**全量权限码字面列表**（非通配符），前端 hasAccessByCodes 字面匹配。

## 3. 功能模块

### 3.1 系统管理（/system）

| 功能 | 说明 |
|---|---|
| 用户管理 | 账号 CRUD、BCrypt 密码、角色绑定、启/禁用、重置密码（重置为 123456） |
| 角色管理 | 角色 CRUD + 菜单授权树（全选/清空） |
| 菜单管理 | 目录/菜单/按钮三级树 CRUD，权限标识维护 |
| 资源管理 | 文件上传/下载/删除/检索；存储后端 local（默认）/ OBS / MinIO，配置切换不改代码 |

### 3.2 需求管理（/requirement）

| 功能 | 说明 |
|---|---|
| 产品管理 | 产品 CRUD + 模块树 CRUD + 成员授权（创建者自动成为 owner） |
| 需求列表 | 生命周期：草稿→评审中→已确认→已关闭（评审中可打回草稿） |
| 项目管理 | 项目 CRUD + 项目-产品多对多绑定，删除前校验无迭代 |
| 迭代管理 | 迭代 CRUD，开始/结束自动回填实际日期，结束前校验无未完成任务 |
| 任务管理 | 任务 CRUD + 指派 + 状态流转（待处理→进行中→已完成→已关闭，含退回） |
| 任务看板 | Trello 风格看板，拖拽卡片即流转状态，非法迁移回滚 |
| 富文本 | story/task/product/project 描述均为 vditor（WYSIWYG/IR/Markdown 三模式），图片直传资源中心 |
| 数据权限 | product_member 授权单元；越权访问抛 403 |

### 3.3 工单系统（/ticket）

| 功能 | 说明 |
|---|---|
| 提交工单 | 独立页面，所有登录用户可用；富文本描述；创建即委派可选 |
| 工单号 | TK-yyyyMMdd-NNNN，按当日最大号+1（含已删除，防撞号） |
| SLA 策略 | 按优先级配置响应/解决时限（默认 P1:30min/4h、P2:1h/8h、P3:2h/24h、P4:8h/48h） |
| SLA 执行 | 创建/优先级变更时计算 response/resolve deadline；列表实时标红超期 |
| 工单流转 | 待受理→受理→处理中→提交确认→待确认→确认解决/退回→已解决→关闭 |
| 委派 | 创建即委派或受理前后改派；待受理单首次委派/受理记为首次响应 |
| 编辑/删除 | 已解决/已关闭不可编辑；删除清流水 |
| 操作流水 | 创建/受理/转派/备注/状态变更/关闭全程留痕，详情抽屉时间线展示 |
| 操作入口 | 提交工单页 + 列表行操作（编辑/受理/委派/流转/备注/关闭/删除） |

### 3.4 开发者中心（/developer）

| 功能 | 说明 |
|---|---|
| 应用管理 | 第三方 APP CRUD，AppKey/AppSecret 自动生成，Secret 重置（旧密钥立即失效） |
| 接口管理 | 经 knife4j `/v3/api-docs` 一键同步接口清单（默认关闭），支持手工登记；开放的接口才可授权 |
| 授权管理 | 应用-接口授权勾选（全量覆盖），未授权调用 403 |
| 接入指南 | 对接流程/鉴权四件套/签名算法/cURL·Python·Java 示例代码 |
| 开放 API 鉴权 | `X-App-Key/X-Timestamp/X-Nonce/X-Signature`，HMAC-SHA256，±5min 时间窗 + Redis nonce 防重放；APP 虚拟会话 `app:appKey`，接口白名单由拦截器控制 |

### 3.5 通知中心

| 功能 | 说明 |
|---|---|
| 站内信 | NoticeSender SPI（common 模块定义接口，notice 组件实现）；广播给指定用户 |
| 收件箱 | 我的通知页：全部/未读/已读 Tab、单条已读、全部已读、删除 |
| 顶栏集成 | 铃铛未读数 30s 轮询，点击查看/已读/跳转 |

### 3.6 通用能力

| 能力 | 说明 |
|---|---|
| 双通道鉴权 | 登录用户走 Sa-Token Bearer；第三方走 HMAC 签名；同一路径两套逻辑并行 |
| i18n | 全部页面/菜单 zh-CN / en-US 双语 |
| 富文本 | vditor 统一封装 RichEditor 组件 |
| 部署 | Docker Compose（nginx + backend + mysql + redis），Flyway V1-V9 自动迁移 |

## 4. 关键业务规则

1. 工单号防撞：流水号取"含已删除"的最大号+1（原生 SQL 绕过逻辑删除过滤）。
2. 迭代结束前置校验：存在未完成任务不可结束。
3. 需求状态机：0→1→2→3，1 可打回 0；任务/工单同理，非法迁移 400。
4. 删除保护：产品下有需求禁删；项目下有迭代禁删；迭代下有任务禁删；模块下有子模块/需求禁删。
5. 数据权限：task 冗余 project_id，链路 task→project→project_product→product，不依赖 story。
6. APP 通道无用户数据权限（接口白名单控制访问面）。
